## 이름을 직접 바꾸는 방법

1. 왼쪽 `실험 보기`에서 실험을 선택한다.
2. 제목 아래 `✏️ 실험 이름·목적 편집`을 펼친다.
3. 이름, 확인하려는 질문, 분류, 해석 메모를 입력하고 **이름·설명 저장**을 누른다.
4. 제목·선택 목록에 반영되며 서버를 재시작해도 유지된다.

다른 브라우저에서 먼저 수정했다면 덮어쓰지 않고 충돌 메시지를 표시한다.
`저장된 내용 다시 불러오기`로 최신 내용을 불러온 뒤 다시 편집한다. 이 동작은 저장하지 않은 입력을 버린다.
동일한 이름을 여러 실험에 붙이면 선택 목록에 짧은 식별자를 덧붙인다.

## 필요 없는 항목을 목록에서 삭제 / 복원

1. 왼쪽 `이름·보관 관리`에서 실험을 선택한다.
2. `기본 목록에서 삭제 / 보관함에서 복원`을 펼친다.
3. 제외 사유를 입력하고 확인 체크 후 **기본 목록에서 삭제 → 보관함**을 누른다.
4. 복원하려면 `관리할 목록 → 보관함`에서 같은 실험을 골라 **기본 목록으로 복원**을 누른다.

보관한 실험도 `실험 보기 → 보관함`에서 내용을 볼 수 있다.
모든 항목을 보관해 기본 목록이 비어도 숨긴 데이터가 자동으로 다시 나타나지 않는다.
새로 생긴 실험은 `분류 대기`로 표시되므로 이름과 목적을 입력하면 된다.
중복처럼 보이는 과거 폴더도 독립 기록인지 검증되지 않았다면 원본을 삭제하지 않는다.

- `보고서·파일`: 보고서, CSV/그림 다운로드, 원본 ID와 저장 위치.

기존 world 좌표 중첩, 지도 충돌 디버그, 경로계획 비교 등은 `기존 상세 분석 도구`에 유지했다.
기존 도구의 선택 목록에도 새 이름을 표시하며 기본 목록 기준으로 필터링한다.
과거 실험을 기존 도구에서 비교하려면 먼저 기본 목록으로 복원한다.
